# Snap Summary

Chrome extension : Press Ctrl+Shift+Y to screenshot the current tab and get an AI summary from Google Gemini or OpenAI, using your own API key.

## Load it
1. Put these files in a folder.
2. Open `chrome://extensions` and turn on Developer mode (top right).
3. Click Load unpacked and choose the folder.
4. Click the puzzle icon, pin it, open it, and add your API key under Settings.
5. Open any regular website and press the shortcut.
