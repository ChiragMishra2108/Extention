# Snap Summary

Chrome extension (Manifest V3): press Ctrl+Shift+Y (Command+Shift+Y on Mac) to screenshot the current tab and get an AI summary from Google Gemini or OpenAI, using your own API key.

## Load it
1. Unzip so you have the `snap-summary` folder.
2. Open `chrome://extensions` and turn on Developer mode (top right).
3. Click Load unpacked and choose the `snap-summary` folder.
4. Click the puzzle icon, pin Snap Summary, open it, and add your API key under Settings.
5. Open any regular website and press the shortcut. Change it at `chrome://extensions/shortcuts`.
